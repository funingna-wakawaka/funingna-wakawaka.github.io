software

但是不幸的是对于安卓机来说没有办法使用Claudecode，所以我们需要安装Ubuntu

因为Android的底层是Linux所以用termux很容易实现Linux的安装

然后进入Ubuntu

成功的话可以看到root@localhost:~#

也就是已经是root模式，不需要在前面添加sudo命令了

然后我们输入以下命令检查环境

只要是显示为Linux和root即可

Ubuntu 官方源里的 Node.js 版本通常较旧，Claude Code 需要较新版本。建议用 NodeSource 安装 LTS 版

下载并执行 NodeSource 安装脚本（以 Node 24 LTS 为例）

不过恢复的话也很简单，Ubuntu执行

nano ~/.claude/settings.json进行编辑

我们需要先授权termux手机存储的访问

termux-setup-storage

然后进入指定目录例如

/storage/emulated/0/MyProject

看看是否可以访问

注意路径不要有中文

由于Android和Ubuntu的文件系统表示方式不太一样，所以还需要操作

我们进入Ubuntu

输入 ls /storage/emulated/0看看Ubuntu是否能访问Android文件

可以访问就执行进入文件路径

cd /storage/emulated/0/MyProject

此时在Ubuntu里显示的是

/mnt/sdcard/MyProject

实际上是同一个路径，只是表达方式不同

然后启动打开codex或者claude 输入提示词

然后就可以看到这个文件夹里有生成的脚本

当然,手机其实也可以写脚本,可以用Acode这个软件,这个是类似VScode的一个插件化编辑器

不过以前VScode可以通过code FA来在移动端上写脚本

不过我强烈不推荐在手机上写代码,因为这种行为和嘉豪没区别,浪费时间
