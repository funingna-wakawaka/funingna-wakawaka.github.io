Zed MCP / Context Server 推荐清单

根据当前 Zed Extensions 中的 MCP / Context Server 列表，结合我的实际开发方向进行筛选。

我的主要开发方向：

  • Astro / Hexo Blog
  • WPF / Viora
  • Love2D
  • GitHub
  • Web / UI / Shader
  • Cloudflare / Vercel
  • AI Coding Agent / ZCode / Zed Agent

原则：不是 MCP 越多越好，而是只安装真正能补充 Coding Agent 能力的 MCP。

一、★★★★★ 强烈推荐

这些是最值得长期保留的。

1. Context7 MCP Server

推荐等级：★★★★★

用途：

让 AI 获取当前版本的库/框架文档，而不是完全依赖模型训练数据。

适合：

  • Astro
  • React
  • Vue
  • Node.js
  • npm 包
  • Tailwind
  • 各种 Web 框架
  • 各种第三方 SDK

我的使用场景：

为什么适合我：

我经常让 AI 修改 Astro、Node.js、各种 npm 项目，而这些项目 API 更新很快。

Context7 是当前 Zed MCP 列表中下载量最高的一批，约 16.6 万下载。

结论：必装。

2. GitHub MCP Server

推荐等级：★★★★★

用途：

让 Agent 更深入地使用 GitHub。

可以用于：

  • Repository
  • Issue
  • Pull Request
  • GitHub 文件
  • 项目内容
  • 仓库相关操作

我的使用场景：

我本身大量使用 GitHub，因此这个 MCP 的实际价值非常高。

当前约 11.3 万下载。

结论：必装。

3. Firecrawl MCP Server

推荐等级：★★★★★

用途：

让 AI 更方便地抓取和理解真实网站。

特别适合：

  • 阅读网站
  • 阅读在线文档
  • 分析网页
  • 抓取网页内容
  • 研究其他项目的网站实现

我的使用场景非常明显：

我经常会给 AI GitHub 项目、网站、在线文档，让它分析后实现。

因此这个 MCP 非常适合我的工作流。

结论：推荐安装。

4. Puppeteer MCP Server

推荐等级：★★★★★

用途：

让 Agent 操作真实浏览器。

例如：

  • 打开网页
  • 点击
  • 输入
  • 获取页面状态
  • 截图
  • 检查网页交互

这对我尤其重要，因为我经常让 Coding Agent 修改：

  • Astro 页面
  • Blog UI
  • 手机端 UI
  • CSS 动画
  • 交互效果

可以形成：

Zed 当前约 5.3 万下载。

结论：推荐安装。

十三、一个重要提醒

不要把所有 MCP 全部打开。

Zed 支持通过 Agent Profiles 控制某个 Agent Thread 可以使用哪些工具，也支持单独控制 MCP 工具权限。

因此我更推荐：

而不是所有 MCP 永久同时启用。

这对你这种经常让 AI 长时间自主修改项目的使用方式尤其重要：工具越多，不一定越好；应该让当前任务只有相关工具可用。

核心原则：MCP 是能力扩展，不是 AI 的“技能点收集游戏”。

你的最佳配置应该是“少量高价值 MCP + 按项目启用专用 MCP”。

目前 Zed 官方也明确支持从 Extensions 安装 MCP、添加 Local/Remote MCP，并可以在 Agent Profiles 中控制工具；另外官方正在逐步向 MCP Registry 方向迁移，因此以后 MCP 的安装/分发方式可能还会变化。
