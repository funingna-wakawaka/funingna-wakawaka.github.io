想制作一个终末地聊天APP

Kotlin Android

之前看到一个UP制作了一个明日方舟的聊天APP

我下载了之后感觉非常有意思,用的是Deepseek的API,就是让明日方舟的角色和玩家聊天

不过这个APP界面很简陋,有点像早期的QQ界面

我产生了一个想法就是能不能制作一个终末地的APP,现在我看B站很多卖课的都在大力推荐Java,说实话,现在的APP基本上都是用的Kotlin来写的,而且谷歌官方也建议Kotlin

这个APP的界面可以像微信和QQ那样自定义聊天界面,然后聊天的角色就是每个角色提前设置好角色的语气和性格,还有记忆存储

当然肯定不是纯聊天,我看看能不能内置一些小游戏,比如斗地主,俄罗斯方块,还有五子棋,音游,模拟经营等等等等

UI和画风的话我可以模仿一下taptap里的一个二次元斗地主游戏的风格

​

这里我设想的是尽量增加AI在游戏中的参与度,让玩家感觉自己被“真人陪伴”

比如斗地主就让AI角色和玩家玩,俄罗斯方块的话可以将俄罗斯方块和开心消消乐结合,五子棋的话就是将五子棋和galgame结合,

音游就是字面意思,可以搞一个人机PK(当然人类肯定打不过AI,所以需要给AI降智操作),模拟经营就是田园生存或者商店经营就像这个早年我喜欢玩的动物餐厅一样

​

总之AI时代,没有做不到,只有想不到,反正借这个机会学学Android开发也不是不行

至于Unity的学习,以后再说吧—要不是Unity总是反复搞事搞得我不敢学这玩意了

思路是这样的

先制作聊天APP->再加入类似QQ的相册功能->再塞进去几个小游戏

所以重点就是聊天APP,我需要让AI更像真人,每个角色性格各异,会聊天,会说梗,会互相@,会发表情包,会水群,如果挂后台的话会自己聊天,玩家被@到时会像QQ微信一样消息提醒用户

我给你讲清楚：网页 → APP（手机 + 电脑）是完全可行的，而且是主流做法

一、网页真的可以变成APP吗？

👉 可以，有三种方式（从简单到专业）

① PWA（最推荐🔥）

👉 本质：网页伪装成APP

能做到：

  • 添加到手机桌面（像APP图标）
  • 全屏打开（没有浏览器UI）
  • 支持通知（部分）
  • 可离线（缓存）

📱 手机上的效果：

就像：

  • 微信里打开的小程序
  • 或一个简单APP

👉 用户基本分不出来

💻 电脑也可以：

  • Chrome / Edge → “安装应用”
  • 直接变成一个窗口应用

👉 适合你现在阶段：完美

② Electron（电脑端）

👉 本质：用浏览器包一层APP壳

例子（你肯定用过）：

  • Visual Studio Code
  • Discord

👉 都是网页做的

能做到：

  • 真·桌面软件
  • 系统通知
  • 文件读写
  • 后台运行

👉 缺点：

  • 占内存大
  • 但开发简单

③ 原生APP（Android Studio）

👉 最正统，但最难

  • Android Studio

👉 适合后期，不适合你现在

二、你这个项目的最佳路线（直接照做就行）

🟢 阶段1（现在就做）

👉 做一个：

手机能打开的聊天网页

  • Vue / React
  • WebSocket
  • AI聊天

🟢 阶段2

👉 变成APP：

  • 加 PWA 支持
  • 手机 → 添加到桌面

🟢 阶段3（电脑）

👉 用 Electron 打包：

  • 直接变成PC客户端

🟢 阶段4（可选）

👉 再考虑 Android Studio

因为：

👉 一套代码，多端运行

你写一次网页：

平台 运行方式

电脑 浏览器 / Electron

const app = express();
const server = http.createServer(app);
const io = new Server(server, {
  cors: { origin: "*" },
});

// 👥 角色设置
const roles = {
  阿刀: "毒舌，喜欢怼人，说话很短",
  小白: "憨，经常问号",
  老哥: "爱玩梗，经常笑死、草",
};
const roleNames = Object.keys(roles);

// 📝 DeepSeek REST API 配置
const DEEPSEEK_API_KEY = "DeepseekAPI";
const DEEPSEEK_MODEL = "deepseek-chat";
const DEEPSEEK_URL = "https://api.deepseek.com/v1/chat/completions";

// 🧩 监听前端连接
io.on("connection", (socket) => {
  console.log("有人连接");

  socket.on("userMsg", async (msg) => {
    console.log("收到用户消息:", msg);

    // 1️⃣ 显示用户消息
    io.emit("msg", { name: "你", text: msg });

    // 2️⃣ 随机选一个角色回复
    const roleName = roleNames[Math.floor(Math.random() * roleNames.length)];

    // 3️⃣ 构造 Prompt
    const prompt = `
你是${roleName}
性格：${roles[roleName]}
你在QQ群聊天，风格要像真人
规则：
- 只说一句话
- 不超过15个字
- 不要解释
- 可以敷衍、吐槽、玩梗
- 不要像AI

用户说：
${msg}

你回复：
`;

    try {
      const response = await axios.post(
        DEEPSEEK_URL,
        {
          model: DEEPSEEK_MODEL,
          messages: [{ role: "user", content: prompt }],
        },
        {
          headers: {
            Authorization: `Bearer ${DEEPSEEK_API_KEY}`,
            "Content-Type": "application/json",
          },
          proxy: false, // 如果你在国内，可能需要设置代理
        },
      );

      console.log("原始返回数据:", response.data);

      const reply =
        response.data.choices[0]?.message?.content?.trim() || "AI没有返回内容";
      console.log("AI回复:", reply);

      io.emit("msg", { name: roleName, text: reply });
    } catch (err) {
      console.error("AI错误:", err.response ? err.response.data : err.message);
    }
  });
});

// ❌ 关闭自动水群，如果只想 AI 回答用户

server.listen(3000, () => {
  console.log("服务器运行：http://localhost:3000");
});

// ================= 🧠 工具 =================
function getRecentHistory() {
  return world.history
    .slice(-12) // 稍微多给一点上下文
    .map((m) => `${m.name}：${m.text}`)
    .join("\n");
}

function isRepeat(text) {
  // 防止简单的复读
  return world.history
    .slice(-8)
    .some((m) => m.text.includes(text) || text.includes(m.text));
}

function tooManyMentions(text) {
  return (text.match(/@/g) || []).length > 1;
}

function validateMessage(text, roleName) {
  if (!text) return false;
  if (text.length > 30) return false; // 放宽一点点长度，让说话更有逻辑
  if (isRepeat(text)) return false;
  if (tooManyMentions(text)) return false;
  return true;
}

// 分离 System Prompt，利用好 DeepSeek 的角色扮演能力
function buildSystemPrompt(role) {
  return `
${WORLD_SETTING}

当前你要扮演的角色是：【${role.name}】
【你的设定】：${role.setting}
【你的说话风格】：${role.style}

任务：
根据群聊记录，以【${role.name}】的身份回复一句话。
要求：
1. 字数控制在15字以内，极简。
2. 绝对不带引号，绝对不要在开头加上自己的名字（如不要输出"阿刀：xxx"）。
3. 如果“你”刚发了言，必须针对“你”的话进行回复！
`;
}

// ================= 🤖 AI =================
async function aiReply(roleName) {
  const role = world.roles[roleName];
  const systemPrompt = buildSystemPrompt(role);
  const userPrompt = `【群聊历史记录】\n${getRecentHistory()}\n\n请【${role.name}】发言：`;

  try {
    const res = await axios.post(
      URL,
      {
        model: "deepseek-chat",
        messages: [
          { role: "system", content: systemPrompt },
          { role: "user", content: userPrompt },
        ],
        temperature: 0.8, // 稍微提高发散性，避免死循环
        presence_penalty: 0.6, // 惩罚重复话题
        frequency_penalty: 0.6,
      },
      {
        headers: { Authorization: `Bearer ${API_KEY}` },
      },
    );

    let text = res.data.choices[0].message.content.trim();

    // 过滤掉AI可能自己加的名字前缀，比如 "阿刀：别吵了" -> "别吵了"
    text = text.replace(new RegExp(`^${roleName}[:：]`), "").trim();
    // 过滤掉首尾的双引号
    text = text.replace(/^["']|["']$/g, "").trim();

    // ❗过滤
    if (!validateMessage(text, roleName)) {
      return;
    }

    const msg = {
      name: roleName,
      text,
      avatar: role.avatar,
    };

    world.history.push(msg);
    io.emit("msg", msg);

    console.log(`[${roleName}] ${text}`);
  } catch (e) {
    console.error("❌ AI错误:", e.response?.data?.error?.message || e.message);
  }
}
